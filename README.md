# RuDao — Beyond The Art of War

The official website for **RuDao** (儒道), a book by **Tony Tong (唐儀)**.

> Beyond The Art of War — The Confucian Co-opetition Way to Balanced Profit and Enduring Partnerships.
> 儒道 - 超越孫子兵法 - 平衡利潤與長久夥伴關係的儒家競合之道

## Sections

1. **Hero** — Title, calligraphy, bilingual subtitle
2. **Concept** — Old Way (兵家之道) vs RuDao Way (儒商之道)
3. **The Book** — Description + 3D cover mockup
4. **Editions** — Three cover designs (Heritage / Scholar's / Quiet)
5. **Five Pillars** — 仁 義 禮 智 信 (The Five Constants)
6. **Lineage** — 儒商 · 儒將 · 天人合一
7. **Author** — Tony Tong (唐儀) bio + social links
8. **Pre-Order** — Email capture + format cards
